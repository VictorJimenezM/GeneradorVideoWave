# SOUNDWAVE RENDER

Una aplicación altamente sofisticada hecha con IA que corre 100% en el navegador.

## 🚀 Características Clave
- **Arquitectura de Agentes:** Impulsado por un sistema multi-agente detallado en [AGENTS.md](./AGENTS.md).
- **Zero Backend / Zero API:** No requiere servidores, bases de datos ni llaves de API externas.
- **Privacidad por Diseño:** Todo el procesamiento ocurre en el lado del cliente (frontend).

## 🛠️ Instalación y Uso Local
1. Clona el repositorio: `git clone ...`
2. Instala las dependencias: `npm install` (o el comando que uses)
3. Corre el proyecto: `npm run dev` (abre `http://localhost:3000`)
